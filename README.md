# 镜花缘

取材自清代李汝珍《镜花缘》的简体中文第三人称 3D 探索游戏。随唐敖、林之洋、多九公乘船出海，走进君子国，在一桩反向讨价还价里体会「好让不争」。本项目从用户保留的原源码建立，原始文件仍在上级目录，未覆盖或删除。

## 当前版本：第一章 · 君子国

本版开放海船甲板和君子国。主线包括船上序章、航海图启航、自由游览、替买卖二人评理、拾取镜花、归舟返航和首章收束。错误答案会给出对应反馈并可重试；游记不是通关门槛。第一章完成后可重游，不重复计入镜花。

码头「归舟渡」、牌坊「惟善为宝」、市场「让利集」、巷口「礼让巷」、山亭「听涛亭」均有可读路牌或人物见闻。实时地图显示真实海岸线、小路、当前位置、朝向、主线目标与距离；选中地标可增加辅助指引，不会传送，也不会覆盖主线任务。五处见闻在阅读后收入游记。

大人国、两面国、无肠国、白民国、黑齿国和小蓬莱仍为**制作中**，航海图可看介绍但不能启航。旧版章节代码保留在 `drafts/`，未混入可玩场景。

## 操作

| 操作 | 键盘 / 鼠标 | 手机 |
| --- | --- | --- |
| 行走 | WASD 或方向键 | 左侧摇杆 |
| 转视角 | 按住鼠标拖动 | 右侧滑动 |
| 快走 / 跳跃 | Shift / 空格 | 跳跃按钮 |
| 交谈、读牌、登船 | E | 互动按钮 |
| 展开岛图 | M 或小地图按钮 | 小地图按钮 |
| 航海图 | 右上航海图按钮 / 甲板图桌 | 同左 |
| 暂停 | Esc | 暂停按钮 |

在岛图里按 M、Esc 或关闭按钮返回游戏。设置中可切换「精细人物」和「轻量 Q 版」：精细模式复用已压缩 GLB；Q 版复用原项目已有的程序化纸偶回退，跳过精细人物下载，保留场景与主线。切换会重新进入当前场景，但不清除进度。

## 人物动画与精修海图

主角不再靠整个网格左右摇摆来假装走路。`src/game/character-animation.ts` 在角色加载时建立 17 骨的人体层级、每顶点最多四路归一化蒙皮权重和真实 `SkinnedMesh`；`AnimationMixer` 在待机、行走、快走、跳起与下落之间平滑切换，四肢关节独立运动，步频随控制器速度变化。精细人物与 Q 版均可使用。派生几何和骨骼单独回收，原模型纹理与缓存不被销毁。

这是依据现有网格推断的运行时自动蒙皮与程序化骨骼动作，不是逐点手工权重或动捕；长袍的步幅采用保守设置以减少接缝与过度拉扯。源 GLB 原文件保留不变，骨骼与动作由可编辑代码生成。

本轮航海图参照了 [《小王子：星辰之旅》](https://littleprince.dev/) 的实际「小王子的旅程」地图，借鉴立体小景、画卷边缘、云雾遮罩和选中光环，保持青绿山水与海上奇游题材，不复制该游戏图像。`ui/island-portraits.ts` 用现有建筑和自然模型在透明画布上生成七国缩略图；不重新生成模型，不增加动捕或贴图依赖。群岛画卷保留七个国名按钮、真实章节状态及启航规则，手机不依赖横向拖动寻找入口；减少动态设置仍生效。

## 存档与恢复

localStorage 使用原键 `jinghua.save`，兼容旧存档。解谜成功、镜花拾取、游记阅读和章节完成分别立即保存。已解谜未拾花时，重新打开游戏点「继续」会恢复岛屿与镜花；已拾花时不会重复生成，仍可返航。完整章节须登船返航后记为完成。私密浏览或存储满时会保持本次会话的内存进度，但无法保证关闭浏览器后的恢复。

## 开发与验证

```bash
pnpm install
pnpm dev                 # 读取已声明 PORT，当前 Session 为 3000
pnpm test                # 进度、存档、地图比例、预览、游戏循环、调参
pnpm build               # 素材恢复、类型检查、Vite、体积检查、分享标签
URL=http://127.0.0.1:3000/ node scripts/smoke.mjs  # 开发版端到端检查
node scripts/smoke.mjs   # 启动 dist/ 本地预览后检查生产版
python3 scripts/subset-font.py                  # 新增中文文案后更新字形
```

`src/game/voyage.ts` 负责场景、互动、地图快照和进度闭环；`chapters/junzi.ts` 是首章；`navigation.ts` 的地标与道路由场景和 UI 共用；`ui/local-map.ts` 增量更新地图；`progress.ts` 提供纯函数存档迁移；`dispose.ts` 清理场景自有资源而保留共享模型。地形与碰撞沿用 Three.js + Rapier，素材不重新生成整套。

运行素材和字体保留在本地，`assets.lock.json` 登记新项目独立存储的哈希与分组，`scripts/manus-game-assets/` 在干净检出时恢复素材。按用户指定正式标题复用原始《镜花缘》封面，保留旧版封面，镜花图标继续复用；`game-sharing.json` 只描述当前真实可玩内容。项目 ID、内部包名和 `jinghua.save` 存档键不因改名变化，保存版本不代表公开发布。

## Preview Tweak

沿用 `src/game/tuning.ts` 游戏参数管理器和 `scripts/manus-tuning/adapter.js` 开发桥接，生产版不注入桥接。保持稳定参数 ID 与真实玩法消费端；Apply 只改预览状态，不写 localStorage 或源码默认值。以平台 Save with Manus 保存调参时，使用正常 Three.js 构建与检查点流程，不另建参数存储。
