# 镜花缘 · 百花航海篇

取材自清代李汝珍《镜花缘》的简体中文第三人称 3D 探索游戏。随唐敖、林之洋、多九公乘船出海，历经九国风物与小蓬莱，在十章航程中收集六枚镜花，并由唐小山的视角照见故事前因与归处。

## 百花航海篇

- 十章可玩：君子国、大人国、无肠国、黑齿国、白民国、淑士国、两面国、歧舌国、女儿国、小蓬莱。
- 三幕序章补入百花谪凡、唐敖仕途与梦神观；海船夜航加入花梦、家信和人物复盘。
- 六国保留原有镜花谜题，并新增市场互让、云色之辨、碑廊论学、同游美馆、食而复取、换衣试人等原著事件。
- 淑士国、歧舌国、女儿国为人物见闻章，不产镜花；女儿国可实际切换林之洋与唐敖双视角。
- 小蓬莱包含两种结局与唐小山尾声；六枚镜花仍分别来自六个产花章。
- 真实 Three.js 地形、建筑、植被与 Rapier 碰撞，唐敖骨骼蒙皮动画及 NPC 分部位动作。
- 九国与仙山具有独立地域风貌，配有手绘航海图、实景岛图、实时位置、任务距离、地标和游记。
- 原创动态管弦配乐、地域变奏、场景音效与对话混音。
- 章内检查点、自动保存、刷新恢复、线性十章解锁，以及旧版七章存档兼容迁移。
- 键盘、鼠标及手机横竖屏触控。

普通入口使用正式存档 `jinghua.save`。在 URL 后添加 `?test=1` 可打开十章测试模式，全部港口开放并固定持有六枚镜花，使用独立存档 `jinghua.save.test`，不会修改正式进度。

## 本地开发

需要 Node.js 22 和 pnpm 10。

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

生产文件输出到 `dist/`。Vite 使用相对资源路径，可部署到域名根目录或 GitHub Pages 项目子路径。

## 自动部署

`.github/workflows/deploy-pages.yml` 在主分支推送后安装依赖、执行生产构建，并将 `dist/` 发布到 GitHub Pages。仓库 Settings → Pages 的 Source 选择 GitHub Actions。

## 主要结构

- `src/game/chapters/`：海船、十章场景、任务和剧情。
- `src/game/voyage.ts`：场景切换、交互、导航与进度闭环。
- `src/engine/`：输入、音频、物理、渲染、存档与固定步长循环。
- `src/ui/`：航海图、岛图、对话和触屏界面。
- `assets/models/`：正式运行用压缩模型。
- `public/audio/`：本地管弦采样及许可。
- `public/interface/`：航海图、岛图和 HUD 缩图。

历史构建、验收截图、源模型和生成候选不进入发布仓库。验收脚本位于 `scripts/`，包括完整通关、刷新恢复、手机地图、视觉和上线专项检查。
